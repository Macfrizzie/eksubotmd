How to create and set up Google Firebase Firestore

1. Create Project

Visit console.firebase.google.com, log in with Google, and click "Add project".

2. Create Firestore

In sidebar go to Build > Firestore Database > Create Database. Choose your location and choose "Start in Test mode".

3. Copy Project ID

Click ⚙️ Project settings > General. Copy the Project ID (e.g., eksubot-ai-12345).

4. Connect & Backup

Paste your Project ID above, click Save, then click Push to Cloud to sync all bot data!

How Agent Mode Works:

When an inquiry cannot be answered by the Knowledge Base, the bot pauses auto-replying to that user and sends a WhatsApp alert to the bot owner. You can chat with them directly, and when you are done, click Resume AI below (or send .airesume <number> in WhatsApp) to hand the chat back to the AI assistant.
